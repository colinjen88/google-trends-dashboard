## 📋 使用指南

### 🚀 快速開始
```bash
# 1. 下載專案
git clone https://github.com/your-username/google-trends-dashboard.git

# 2. 進入目錄
cd google-trends-dashboard

# 3. 啟動伺服器
python -m http.server 8000

# 4. 開啟瀏覽器
http://localhost:8000
```

### 📖 基本操作
1. **新增圖表**：輸入關鍵字 → 選擇地區和時間 → 點擊新增
2. **移除圖表**：點擊圖表右上角 ✕ 按鈕
3. **響應式檢視**：調整瀏覽器視窗大小觀察佈局變化

### ⚙️ 自訂設定
- **修改預設圖表**：編輯 `index.html` 中的圖表區塊
- **調整樣式**：修改 `assets/css/styles.css`
- **擴展功能**：修改 `assets/js/dashboard.js`
